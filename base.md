## Plataforma de Gerenciamento de Carteiras de Investimentos

### Visão Geral
Uma plataforma clean e moderna para múltiplos usuários gerenciarem suas carteiras de renda fixa e variável, com dashboards completos e análise detalhada.

---

### 🏠 **1. Página de Autenticação**
- Login e cadastro de usuários
- Design clean com visual profissional
- Validação de formulários

---

### 📊 **2. Dashboard Principal**
- **Resumo do patrimônio total** com valor atualizado
- **Gráfico de alocação** por tipo de ativo (pizza)
- **Rentabilidade geral** com comparativo mensal
- **Cards de destaque**: maior alta, maior baixa, próximos vencimentos
- **Gráfico de evolução patrimonial** ao longo do tempo

---

### 💼 **3. Gestão de Carteira - Renda Fixa**
- Lista de ativos (CDB, LCI, LCA, Tesouro, Debêntures)
- Informações: valor investido, data de vencimento, taxa, rentabilidade
- Formulário para adicionar/editar ativos
- Filtros por tipo de ativo e vencimento

---

### 📈 **4. Gestão de Carteira - Renda Variável**
- Lista de ações, FIIs, ETFs, BDRs
- Preço médio, quantidade, valor atual, variação %
- Histórico de proventos (dividendos, JCP)
- Formulário para registrar compras/vendas

---

### 📁 **5. Importação de Dados**
- Upload de arquivos CSV/Excel
- Preview dos dados antes de confirmar importação
- Mapeamento de colunas
- Layout para futura integração com corretoras

---

### 📉 **6. Análise Detalhada**
- **Gráficos de evolução** por ativo individual
- **Comparação com índices** (Ibovespa, CDI, IPCA)
- **Histórico de dividendos** com projeção
- **Performance por setor** (bancos, varejo, etc.)

---

### 🤖 **7. Chat IA - Assistente de Investimentos**
- **Chat interativo** com IA para tirar dúvidas gerais sobre investimentos
- **Análise personalizada** da carteira do usuário
- **Respostas contextualizadas** sobre ativos específicos
- **Sugestões de rebalanceamento** baseadas no perfil
- **Explicações educativas** sobre conceitos financeiros
- **Histórico de conversas** salvo para consulta futura
- Interface clean com design moderno integrado ao tema

---

### ⚙️ **8. Configurações**
- Perfil do usuário
- Preferências de exibição
- Metas de alocação
- Exportação de dados

---

### Design
- **Estilo**: Clean e moderno com fundo claro
- **Cores**: Tons neutros com destaques em verde (ganhos) e vermelho (perdas)
- **Gráficos**: Usando Recharts (já instalado)
- **Responsivo**: Funciona bem em desktop e mobile

---

### Observações Técnicas
- Layout completo com dados de exemplo (mock data)
- Estrutura preparada para conexão futura com backend (Supabase)
- Todas as telas funcionais para navegação
- Integrações com corretoras e APIs de cotação poderão ser adicionadas posteriormente
