# 🤖 Guia Rápido - Chat IA com sua própria API Key

## O que mudou?

Agora você pode usar sua própria API key do OpenAI para conversar com o assistente de IA! Isso significa:

✅ **Mais privacidade** - Suas conversas usam sua própria conta OpenAI  
✅ **Controle total** - Você gerencia seus próprios custos e limites  
✅ **Segurança** - Sua API key é criptografada e armazenada com segurança  
✅ **Respostas reais** - Usa o ChatGPT (GPT-3.5-turbo) para respostas inteligentes  

## Como configurar (3 passos simples)

### 1️⃣ Obtenha sua API Key do OpenAI

1. Acesse: https://platform.openai.com/api-keys
2. Faça login ou crie uma conta
3. Clique em "Create new secret key"
4. Copie a chave (começa com `sk-...`)

💡 **Dica**: Você precisará adicionar créditos na sua conta OpenAI. O custo é muito baixo (centavos por conversa).

### 2️⃣ Configure no sistema

1. Abra a página **Chat IA** no menu lateral
2. Clique no ícone de **⚙️ Configurações** no canto superior direito
3. Cole sua API key no campo
4. Clique em **Salvar**

### 3️⃣ Comece a conversar!

Pronto! Agora você pode fazer perguntas sobre investimentos e receber respostas inteligentes do ChatGPT.

## Exemplos de perguntas

- "Como devo diversificar minha carteira?"
- "Qual a diferença entre CDB e Tesouro Direto?"
- "Vale a pena investir em ações de dividendos?"
- "Como calcular o rendimento do meu investimento?"
- "Explique o que é IPCA+"

## Segurança

🔒 **Sua API key está segura!**

- Criptografada com AES-256 antes de ser salva
- Nunca é exposta em logs ou telas
- Apenas você tem acesso
- Pode ser removida a qualquer momento

## Custos

O uso da API do OpenAI tem custo, mas é muito baixo:

- **GPT-3.5-turbo**: ~$0.002 por 1000 tokens
- Uma conversa típica usa ~500 tokens
- **Custo médio**: menos de $0.01 por conversa

💡 A OpenAI oferece créditos gratuitos para novos usuários!

## Problemas comuns

### "Configure sua API key do OpenAI"
➡️ Você ainda não configurou sua chave. Siga os passos acima.

### "Erro ao comunicar com a API"
➡️ Verifique se:
- Sua API key está correta
- Você tem créditos na conta OpenAI
- Sua conta OpenAI está ativa

### "Insufficient quota"
➡️ Você precisa adicionar créditos na sua conta OpenAI:
https://platform.openai.com/account/billing

## Gerenciar suas API Keys

Para ver, atualizar ou remover suas API keys:

1. Clique em **⚙️ Configurações** na página do Chat
2. Suas keys aparecerão mascaradas (****1234)
3. Você pode adicionar uma nova key ou remover a existente
